# Paraph Café Menu · کافه پاراف

A luxury boutique bilingual (Persian / English) digital menu, interactive order tray, counter payment showcase, and single-password administrative management system for Paraph Café.

## Features

- **Bilingual Interface**: Seamless Persian (`fa`, RTL) and English (`en`, LTR) navigation.
- **Dynamic Menu**: Categorized offerings with customizable options, allergen notices, and pricing.
- **Interactive Tray**: Instant item selection, quantity toggling, and cost tally.
- **Counter Payment Display**: Dedicated checkout and order receipt screen.
- **Admin Dashboard**: In-browser item management, price updates, and JSON import/export.
- **Ultra-Fast Static Deployment**: Hosted directly on GitHub Pages with zero external backend dependencies.
